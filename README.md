# 🧾 Controlorça – Site Oficial

Este repositório contém o código-fonte do site oficial do **Controlorça**, uma plataforma desenvolvida para facilitar a criação e o gerenciamento de orçamentos de maneira simples e eficiente.

🔗 Acesse a aplicação: [budget-blitz-creator.vercel.app](https://budget-blitz-creator.vercel.app)

---

## 🎯 Objetivo

Apresentar a ferramenta **Controlorça** de forma clara e objetiva, destacando suas funcionalidades, benefícios e orientações de uso para auxiliar usuários no controle financeiro.

---

## 🛠️ Tecnologias Utilizadas

- **CSS3**: Estilização responsiva e moderna.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
- **Vite**: Ferramenta de build rápida para projetos web modernos.
- **Tailwind CSS**: Framework utilitário para estilização rápida e consistente.
- **Supabase**: Backend como serviço para autenticação e banco de dados.
- **Bun**: Gerenciador de pacotes e runtime JavaScript moderno.

---
